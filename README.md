# FP Txurdinaga · Frontend

Interfaz de demostración en euskera, hecha con HTML, CSS y JavaScript nativo. No necesita PHP, API ni base de datos.

## Abrir

Abre `index.html` en un navegador o usa Live Server en VS Code. La portada y el dashboard son dos vistas de la misma página; **Sartu** cambia de vista sin recargar.

## Archivos

- `HTML/index.html`: portada y dashboard.
- `CSS/estilos.css`: diseño adaptable y temas claro/oscuro.
- `JS/dashboard.js`: navegación, reloj y registros de demostración.
- `JS/theme.js`: cambio de tema persistido en el navegador.
- `IMG/Logotipo_Txurdinaga.png`: logotipo usado por la interfaz.

Los registros iniciales son de muestra. Los nuevos accesos se guardan en `localStorage` de ese navegador; no se envían a ningún servidor.
